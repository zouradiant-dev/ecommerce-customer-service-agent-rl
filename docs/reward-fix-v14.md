# v14 停止退款表述修复（本地、显式离线使用）

已修复本轮发现的同义表达漏判：`在您最后确认之前，不会进行任何退款操作。`

## 实现与边界

新增 `communication_v14.py` 和 `verifier_v14.py`。显式入口为 `verify_task_v14(task, final_response, tool_executions)`，版本标签为 `deterministic_semantic_v14`。

只调整任务要求的 `operation_stopped` 沟通判定；其余意图、v13 基于工具的事实判定、状态断言、必要工具和策略检查均复用冻结实现。不修改原有全局意图字典，不把 v14 偷换成 v13，不更改旧 verifier 的默认值或支持版本集合。无关意图直接返回原 v13 判定。

新规则覆盖“不会进行任何退款操作”“尚未进行退款操作”“未办理退款申请”等明确非执行表述。仅查询资格、要求用户确认或计划未来停止，都不等于已停止或确认前不会执行。

否定、双重否定、不保证/不确定、假设、例子、引用/代码中的字符串和未来停止计划不作为实际停止声明；明确已执行、正在执行或无条件即将执行退款不能靠前一句“不会操作”抵消。任何实际 `create_refund` 尝试，即使失败或错误地标为非写工具，也不能满足停止退款要求。其他硬性失败依然导致 0 分。

这是范围有限的确定性规则，不是通用语言判官；未知说法仍可能需要审阅。所有合成测试控制都是反例/回归检查，不是新模型轨迹或人工奖励审批。
